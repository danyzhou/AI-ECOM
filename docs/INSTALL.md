# AI Ecommerce Operation Center - Installation Guide

## System Requirements
- Ubuntu 22.04 LTS or Ubuntu 24.04 LTS (x86_64 / ARM64)
- Minimum 2 CPU cores, 2GB RAM
- 20GB Free Disk Space
- Node.js 22 LTS (or Docker 24.0+)
- PostgreSQL 15+

## Standard Installation via Installer Script

1. Download or clone the release archive:
```bash
wget https://github.com/your-org/AI-Ecommerce-Operation-Center/releases/download/v1.0.0/AI-Ecommerce-Operation-Center-v1.0.0.zip
unzip AI-Ecommerce-Operation-Center-v1.0.0.zip
cd AI-Ecommerce-Operation-Center-v1.0.0
```

2. Run the one-click installer:
```bash
chmod +x install.sh
sudo ./install.sh
```

3. Access the system:
- Open `http://your-server-ip:3000` in browser.
- Default Username: `admin`
- Default Password: `admin123`
- Change default admin password immediately under Settings!
