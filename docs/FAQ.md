# Frequently Asked Questions (FAQ)

### Q1: Is this a multi-tenant SaaS?
No. This is a dedicated single-owner enterprise AI operation center designed for personal or team e-commerce operations.

### Q2: How are API keys secured?
API keys are encrypted and processed strictly server-side in Node.js runtime. Keys are never exposed to client browser JS.

### Q3: How to connect WooCommerce store?
In WordPress Admin -> WooCommerce -> Settings -> Advanced -> REST API, generate Consumer Key and Consumer Secret with Read/Write permissions, then add them in system UI under WordPress Stores.
