# Changelog - AI Ecommerce Operation Center

## [v1.0.0] - 2026-07-24

### Initial Release
- **Initial Release**: Full-stack production release candidate.
- **OpenAI Integration**: Vision analysis and image processing for product imagery.
- **Gemini Integration**: High-converting multilingual product copywriting and SEO metadata.
- **WooCommerce Multi Store**: Full WordPress WooCommerce store integration, connection health checks, and direct publishing.
- **Publishing Center**: Single-click and batch publication management across connected stores.
- **SKU Generator**: Custom prefixing, automatic code length padding, and sequential locking.
- **AI Image Optimization**: Watermark removal, background isolation, and image ratio enforcement.
- **Dashboard & Analytics**: Real-time operational metrics, store status tracking, and AI task activity logs.
- **One-Click Automated Deployment**: Full shell installation suite for Ubuntu 22.04 & 24.04 with Docker, Nginx, Let's Encrypt SSL, and Systemd integration.
